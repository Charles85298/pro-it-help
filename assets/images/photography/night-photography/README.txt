Place photographs for the "night-photography" gallery in this folder.

After copying a photo here, open:
assets/js/gallery-data.js

Add its filename to the matching category's photos list.

Example:
{ file: "my-photo.jpg", title: "My Photo Title", alt: "A useful image description" }

Supported browser formats include JPG, JPEG, PNG, WEBP, GIF, and SVG.
For faster website loading, resize large photographs before uploading and prefer JPG or WEBP.
